# ❄️ Generative AI with Snowflake Cortex

> A hands-on learning journey through Generative AI, Snowflake Cortex LLM Functions, and LLM Fine-Tuning — from understanding the foundations to building and deploying an AI-powered application.

---

## 🚀 About This Repository

This repository documents my hands-on journey through **Generative AI with Snowflake**, covering the concepts, notebooks, experiments, and practical implementations from the course.

The journey is organized into three modules:

1. **Module 1 — Introduction to Generative AI**
2. **Module 2 — Snowflake Cortex LLM Functions**
3. **Module 3 — Fine-Tuning Large Language Models**

Rather than only learning the theory, this journey focuses on understanding how LLM capabilities can be integrated with real-world data and transformed into practical AI applications.

The final workflow brings everything together into an AI-powered **Support Ticket Response Application** using Snowflake Cortex and Streamlit.
